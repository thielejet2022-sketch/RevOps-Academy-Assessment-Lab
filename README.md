# RevOps Academy & Assessment Lab

A public, versioned body of work for developing, practicing, evaluating, and codifying Revenue Operations capability through realistic exercises, reusable datasets, competency models, and assessment methodology.

## Repository role

This repository is the canonical home for the Academy's reusable intellectual property and methodology. The ChatGPT Project is the active learning and assessment workspace. JET AIOS governs the Project, but AIOS governance artifacts live separately in `thielejet2022-sketch/JET-EVA-Workspace`.

## V1 structure

- `competency-model/` — what strong RevOps capability looks like
- `datasets/` — reusable, versioned operating realities
- `exercises/` — scenarios and learner/participant tasks referencing dataset versions
- `assessment/` — scoring rubrics, evidence standards, and evaluator guidance
- `methodology/` — durable design and operating methods shared across Academy and Assessment modes

## Public-repository boundary

Do not store participant records, private candidate assessments, confidential employer data, proprietary company datasets, credentials, secrets, or other sensitive material in this repository.

## Design principle

Design for reuse, not commercialization. Start simple, learn through real usage, and add structure only when the work proves it is needed.
